Tennis Swing Analyzer — Prototype

Upload a swing clip, run a full analysis pass, and get estimated racket-hand speed plus a few rule-based technique notes.

Camera assumption for this version: filmed from the side (roughly perpendicular to the swing direction), with the player fully in frame including feet, standing still and upright for at least one moment early in the clip (e.g. the ready position) — that frame is used to calibrate real-world scale from your height.
Setup required: this uses real Supabase auth/database and real Stripe payments. See README.md for the full setup steps (Supabase project + SQL schema, Stripe products/prices, deploying the two Edge Functions, and filling in config values below) before this will work end to end.
